# Week 3 — Python Functions: Intermediate Practice

This week focuses on using Python functions to organize code, perform calculations, validate data, and solve problems through reusable logic.

## 📚 Topics Covered

- Defining and calling functions
- Function parameters and return values
- Lists and dictionaries
- Conditional statements and loops
- Input validation
- Reusable code and modular programming

## 📝 Tasks

### Task 1 — Smart Shopping Receipt Generator

Creates a shopping receipt using reusable functions. Calculates the subtotal, applies discounts, calculates tax, and displays the final purchase amount.

**Key features:**

- Calculate the subtotal of purchased items.
- Apply discounts based on the purchase amount.
- Calculate tax using a specified tax rate.
- Generate a receipt summary.
- Validate prices, quantities, and tax rates.

**File:** `task01_shopping_receipt.py`

### Task 2 — Student Performance Analyzer

Analyzes students' exam results using Python functions. Assigns grades, calculates the class average, identifies the highest and lowest scores, and counts passed and failed students.

**Key features:**

- Validate student scores.
- Assign grades using the specified grading scale.
- Calculate the class average.
- Identify the highest and lowest scores without using built-in `max()`, `min()`, or `sum()` for the main calculations.
- Count passed and failed students.
- Identify students who scored above the class average.
- Generate a class performance report.

**Passing score:** 50

**File:** `task02_student_analyzer.py`

### Task 3 — Advanced Number Analyzer

Analyzes a number using reusable Python functions. Checks whether it is even or odd, determines whether it is prime, calculates the sum of its digits, reverses it, and finds its positive divisors.

**Key features:**

- Check whether a number is prime.
- Find the positive divisors of a number.
- Calculate the sum of its digits.
- Reverse a number.
- Generate a complete number analysis.
- Handle zero and negative numbers appropriately.

**File:** `task03_number_analyzer.py`
