# Week 2 — Python Conditions, Loops & Computational Thinking

This folder contains the exercises completed during **Week 2** of the **AKIBA TECHNOLOGIES Software Engineering & Backend Bootcamp**.

## 📚 Topics Covered

* Conditional statements
* `if`, `elif`, and `else`
* Comparison operators
* Logical operators
* `for` loops
* `while` loops
* Modulus operator
* Input validation
* Edge cases
* Computational thinking

## 📝 Tasks

### Task 1 — Even or Odd

Determines whether a number entered by the user is even or odd.

**File:** `task_01_even_odd.py`

### Task 2 — Largest of Three

Compares three numbers entered by the user and determines the largest number.

The program also handles cases where two or all three numbers are equal.

**File:** `task_02_largest_three.py`

### Task 3 — Prime Number Checker

Determines whether a number entered by the user is a prime number using a loop.

The program handles important cases such as `0`, `1`, and `2`.

**File:** `task_03_prime_checker.py`

### Task 4 — Palindrome Checker

Checks whether a word is a palindrome by comparing the word with its reverse.

The program also handles uppercase and lowercase letters.

**File:** `task_04_palindrome.py`

### Task 5 — Sum of Digits

Calculates the sum of all digits in a number using a loop.

**File:** `task_05_sum_digits.py`

### Task 6 — FizzBuzz

Prints numbers within a given range while replacing multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.

**File:** `task_06_fizzbuzz.py`

### Task 7 — Number Guessing Game

Creates a simple number guessing game where the user tries to guess a randomly selected number.

The program provides feedback to help the user determine whether their guess is too high or too low.

**File:** `task_07_number_guessing.py`

### Task 8 — Count Numbers

Processes a series of numbers entered by the user and counts numbers based on the required conditions.

This task focuses on using loops and conditions to process multiple inputs.

**File:** `task_08_count_numbers.py`
