# Week 2 — Python Conditions, Loops & Computational Thinking

This folder contains the exercises and mini project completed during **Week 2** of the **AKIBA TECHNOLOGIES Software Engineering & Backend Bootcamp**.

## 📚 Topics Covered

* Conditional statements (`if`, `elif`, and `else`)
* Comparison operators
* Logical operators
* `for` loops
* `while` loops
* Modulus operator
* Input validation
* Random number generation
* Counters and accumulators
* Edge cases
* Computational thinking

## 📝 Tasks

### Task 1 — Even or Odd

Determines whether a number entered by the user is even or odd.

**File:** `task01_even_odd.py`

### Task 2 — Largest of Three

Compares three numbers entered by the user and determines the largest number. Handles cases where two or all three numbers are equal.

**File:** `task02_largest_three.py`

### Task 3 — Prime Number Checker

Determines whether a number is prime using a loop to check possible divisors. Handles special cases such as `0`, `1`, and `2`.

**File:** `task03_prime_checker.py`

### Task 4 — Palindrome Checker

Checks whether a word reads the same forward and backward. Ignores uppercase and lowercase differences.

**File:** `task04_palindrome.py`

### Task 5 — Sum of Digits

Calculates the sum of the digits in a number using a loop.

**File:** `task05_sum_digits.py`

### Task 6 — FizzBuzz

Prints numbers in a range, replacing multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.

**File:** `task06_fizzbuzz.py`

### Task 7 — Number Guessing Game

Allows the user to guess a randomly selected number and provides feedback to indicate whether each guess is too high or too low.

**File:** `task07_number_guessing.py`

### Task 8 — Count Numbers

Uses loops and conditions to process numbers and count them according to the task requirements.

**File:** `task08_count_numbers.py`

### Task 9 — ATM PIN System

Simulates an ATM PIN verification system, allowing the user to enter a PIN and handling incorrect attempts according to the task requirements.

**File:** `task09_atm_pin.py`

### Task 10 — Number Analyzer

Analyzes a number or a series of numbers using conditions and loops to determine relevant properties based on the task requirements.

**File:** `task10_number_analyzer.py`

## 🚀 Mini Project — Simple Bank Account System

A simple banking program that allows users to check their balance, deposit money, withdraw money, and exit the program through a menu.

The program starts with a balance of **1,000 Birr** and handles invalid menu options and PIN verification.

**File:** `mini_project/bank_account.py`
