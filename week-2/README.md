# Week 2 — Python Conditions, Loops & Computational Thinking

This folder contains the exercises completed during **Week 2** of the **AKIBA TECHNOLOGIES Software Engineering & Backend Bootcamp**.

## 📚 Topics Covered

* Conditional statements
* `if`, `elif`, and `else`
* Comparison operators
* Logical operators
* `for` loops
* `while` loops
* Modulus operator
* Input validation
* Edge cases
* Computational thinking

## 📝 Tasks

### Task 1 — Even or Odd

Determines whether a number entered by the user is even or odd.

The program uses the modulus operator to check whether the number is divisible by 2.

**File:** `task_01_even_odd.py`

### Task 2 — Largest of Three

Compares three numbers entered by the user and determines which number is the largest.

The program also handles cases where two or all three numbers are equal.

**File:** `task_02_largest_three.py`

### Task 3 — Prime Number Checker

Determines whether a number entered by the user is a prime number.

The program uses a loop to check possible divisors and correctly handles values such as `0`, `1`, and `2`.

**File:** `task_03_prime_checker.py`

## 🎯 What I Learned

Through the first three tasks of Week 2, I practiced using conditional statements to make decisions, comparison operators to compare values, and the modulus operator to check divisibility.

I also learned how to use loops to repeatedly check conditions, handle edge cases, and break problems down into smaller steps before writing the solution.

These tasks helped me begin applying **computational thinking** to Python problems instead of simply writing code without first considering the logic.
